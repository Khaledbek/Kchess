Static regression coverage

Opening book rebuild compatibility
- opening_book.kcb format/schema was not changed.
- Runtime contains no 3-month/14-month assumption.
- A broader 14-month KCB rebuild can replace the bundled KCB1 file without changing KCL, KCO, ABI, or Training-Arena code.

Retained legacy data by design
- native/src/training/data/openings_a.inc ... openings_e.inc remain because KCL1 does not encode complete named setup SAN/FEN paths. They are no longer an answer/continuation book.
- PolyGlot support may remain elsewhere in KChess for unrelated functionality/tests, but it is not a productive Training-Arena continuation path.
