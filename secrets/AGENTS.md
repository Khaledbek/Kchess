# Local Secrets

## Scope

`secrets/` contains developer-machine credentials and local provider usage state.

## Rules

- Never commit API keys, tokens or generated usage state.
- `<provider>_api_key.txt` contains only the local API key of one Coach provider. `<provider>` is the id used in `config/coach_provider.json`, for example `gemini_api_key.txt`, `deepseek_api_key.txt`, `claude_api_key.txt` or `openai_api_key.txt`.
- `<provider>_usage.json` is generated by KChess for that provider's rolling request guard.
- Flutter must never read or expose these files; native C++ owns secret access.
