# Local Secrets

## Scope

`secrets/` contains developer-machine credentials and local provider usage state.

## Rules

- Never commit API keys, tokens or generated usage state.
- `gemini_api_key.txt` contains only the local Gemini Authorization Key.
- `gemini_usage.json` is generated by KChess for the rolling request guard.
- Flutter must never read or expose these files; native C++ owns secret access.
